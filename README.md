# Practice Data Analysis
This repository is for learning pandas and matplotlib.
It includes basic exercises and mini projects.

## Projects
- Student Score Analysis
  * Analyze the relationship between study time and score
  * Compare scores by gender
  * Visualize score distribution
- Movie Rating Analysis
  * Compare average ratings by genre
  * Analyze the relationship between runtime and rating
  * Visualize rating distribution
 
## Structure
- notebooks/ : practice files
- projects/ : mini data analysis projects

## Goal
- learn data analysis basics
- Practice visualization
- Build a data analysis portfolio

## Tools
- pandas
- matplotlib
